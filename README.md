# Lonely Chat

AI-powered Twitch chat bots that create engaging, personality-driven conversations in stream chats.

## Setup

```bash
pnpm install
```

## Commands

```bash
vp dev          # dev server
vp check        # format + lint + typecheck
vp lint         # lint only
vp fmt          # format only
vp pack         # production build
vp test         # run tests
```
